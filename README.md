# 我的女友景甜风格文章仿写 Skill

一个用于模仿「我的女友景甜」文风的中文第一人称情感叙事 / 短篇仿写技能（Skill）。

「我的女友景甜」是这套写法的**品牌昵称**——它指代一种特定的情感叙事质感：冷静、克制，用冷峻的数字对比代替抒情，用反高潮代替宣泄。它不是某篇具体文章，而是一种可复用的写作骨架。

> 本 skill 源自我（用户）请 Claude 基于孙宇晨的一篇文章反向提炼出的「冷数字荒诞体」写法，经过二次改造成现在的风格仿写工具。

## 风格特征

这套写法能立住，靠的不是某个具体的「贫富悬殊」或「明星八卦」设定，而是一套统一的骨架 + 七条技法。无论主题怎么换，这些都不能省略：

| # | 技法 | 要点 |
|---|------|------|
| 1 | 开篇：数字对比锚点 | 用两个可类比但量级悬殊到荒诞的具体数值开篇，不加解释，让读者自己拼图 |
| 2 | 对话：极简到近乎脚本 | 不用引号，极短句，重复顺从短句（如「我说好」）作为节拍器 |
| 3 | 细节：精确到荒唐 | 金额、时间、距离、人数精确到不必要，用官僚式精确抽空情感 |
| 4 | 背景劳动意象（隐喻镜像） | 一组「为排场服务但徒劳」的背景动作，反复出现且细节递进 |
| 5 | 权力标记物反复出现与变形 | 一个道具/动作贯穿全篇，每次出现状态都有变化 |
| 6 | 情感高潮处的反高潮处理 | 崩塌是生理性的、近乎临床的冷静动作，而非哭喊 |
| 7 | 结尾：留白式反讽，呼应开篇 | 回到具体场景 + 短句留白，不写教训、不写感悟 |

## 核心结构引擎

**叙述者（「我」）对一个结构上无法真正回应 / 记得 / 珍惜他的对象，投入不断升级的单方面顺从与付出；叙述者始终不拒绝、不设限，直到某个瞬间被辜负或被戳穿，情感才崩塌——但崩塌的表现是反高潮的、近乎临床的，不是哭喊。**

这条「单方面付出不断升级」的轨迹是全篇唯一不能省的内容要素，可用两种方式生成（仅影响情节细节，不影响文笔与技法）：
- **方式一：对方主动加码索取**——适用于对方是人、或有议价能力的角色。
- **方式二：叙述者自己不断加码付出**——适用于对方无法主动索取的对象（AI、逝者、单向关系等）。

## 创作前必须敲定的变量（缺一项不能动笔）

| # | 变量 | 说明 |
|---|------|------|
| 0 | 升级轨迹的生成方式 | 方式一还是方式二（决定下面第 2 条怎么填） |
| 1 | 叙述者「我」 | 姓名/称呼、掌握的外部资源类型、性别不限 |
| 2 | 对方（「女友」/对方角色） | 姓名/爱称；方式一填「索取的东西与递增节奏」，方式二填「自己加码付出的东西与升级」 |
| 3 | 贯穿全篇的核心意象/道具 | 开篇埋下、中段重现、结尾呼应的具体物件或动作 |
| 4 | 开篇数字对比 | 两个量级悬殊的可类比数值，至少一个来自叙述者亲历 |
| 5 | 背景服务劳动意象 | 谁在为「排场」做无意义但精确的重复劳动（隐喻镜像） |
| 6 | 故事基调 | 默认「冷酷荒诞 + 最后情感崩塌」，除非用户指定 |

每一项要么用户明确给出，要么用户授权我生成并展示给用户确认——不允许悄悄跳过。

## 使用示例

> 一颗卵子的重量，三点五微克。
>
> 五千万美元现金的重量，两点五吨。
>
> 她把那张照片设成头像，说好看吗。我说好。
> 又说删了吧，我说好。
> 又说找回来，我说好。
>
> 我把手放在胸口，数了一下。心跳很稳。

（以上仅为风格示意片段，实际使用按变量清单展开成 3000–4000 字中文短篇。）

## 使用方法

在 WorkBuddy 中加载本 skill 后，直接说「仿写」「模仿这种风格写一篇」「按这个感觉写个故事」即可触发。技能会先和你敲定变量清单，再输出完整短篇。

## 说明

- 「我的女友景甜」是风格品牌昵称，指代一种叙事质感，并非对特定人物的限定写法。
- 风格效果高度依赖阅读时的沉浸节奏，成稿后建议直接看全文，再针对具体段落微调。
